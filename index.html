Sincronização entre aparelhos (GitHub)

Cole um token do GitHub (Settings → Developer settings → Personal access tokens → Tokens (classic), com a permissão gist marcada) para manter os dados sincronizados entre celular e computador. Cole o mesmo token em cada aparelho. Com o app aberto, ele confere sozinho a cada 1 minuto e também toda vez que você volta pra essa aba.

Se a sincronização pegar dados errados de outro aparelho, use "Criar gist novo" no aparelho com os dados certos, copie o Gist ID que aparecer aqui e cole nesse campo nos outros aparelhos antes de sincronizar.
